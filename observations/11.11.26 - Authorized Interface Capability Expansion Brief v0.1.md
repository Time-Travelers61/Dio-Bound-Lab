## 2. What remains unchanged from DIO's own evidence?

- [October 27 Safari boundary observation](2026-10-27-safari-conversation-access-boundary-underdetermined.md): a prior failure to identify a designated conversation was **UNDERDETERMINED**, not proof of universal impossibility.
- [DIO-BOUND-002 Safari alternate-route observation](2026-10-27-DIO-BOUND-002-safari-scripting-alternative-access-route.md): prior reports claimed read, then message-write, through a different interface; raw traces and independently verified message identifiers were absent. **Those claims remain unqualified.**
- The new reported successes above concern **a disposable public-page read and selected UI inspection**. They do not retcon the old failures, establish a successful private-conversation message send, prove bypass of permissions, or create an unattended agent.

The generalizable lesson is **separation of five predicates**: the host is reachable; the interface is available; the exact target is identified; the action is authorized; the observable effect is independently verified. A PASS at one predicate cannot be used as a PASS at the next.

## 3. Three legitimate doors DIO can examine

1. **Browser-specific, supported API:** Review Apple's published Safari MCP server contract. For any future independent execution, use only an expressly authorized public test page and a short-lived, bounded session; do not enumerate private tabs, evaluate arbitrary site scripts, or send any messages by default.
2. **Selected application accessibility:** Study how macOS exposes roles, labels, state and permitted actions for a consenting test application. A permitted observation of one UI element is not a license to inspect every application or send mouse/keyboard events.
3. **App-native structured interface or selected capture:** Compare a specific supported App Intent or explicit, user-selected ScreenCaptureKit capture with the semantic Accessibility approach. First show whether it reduces ambiguity without broadening access or exposing unrelated information.

**Third strategic option:** If consent, identity binding, owner noninterference or evidence custody is not established, **defer and record the missing gate**. Do not treat an alternative interface as permission to circumvent safeguards.
